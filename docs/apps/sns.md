# SNS

`/app/sns/` で使える、授業用の小さなSNSです。名前を入力して参加し、文章を投稿します。自分の投稿は編集・削除できます。

- **Python・FastAPI**：ページの表示や投稿の処理を行います。サーバの起動にはUvicornを使います。
- **Jinja2・HTML・CSS**：テンプレートから画面を作り、見た目を整えます。
- **JavaScript・WebSocket**：サーバと接続を保ち、投稿・編集・削除をほかの参加者の画面にもすぐ反映します。データはJSONでやり取りします。
- **SQLite・Cookie**：参加情報をDBに保存し、Cookieで同じブラウザの参加者を確認します。

投稿はメモリに一時保存しているため、サーバを再起動すると消えます。
