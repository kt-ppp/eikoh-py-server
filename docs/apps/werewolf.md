# 人狼

`/app/werewolf/` からルームを作成・参加できる、4〜16人用の人狼ゲームです。ルーム作成者もプレイヤーになり、進行・投票の集計・勝敗判定をサーバが行います。

作成者は開始前に、定員、人狼・占い師・騎士・霊媒師・狂人の人数と、夜・昼の議論・投票の時間を設定します。残りの参加者は村人になります。ルームコードか参加用リンクを共有し、4人以上集まったら開始します。

夜は役職に応じて対象を選び、昼は対面の会話や公開チャットで議論し、投票で人狼を探します。対面で話す場合はチャットへの入力は不要です。役職、占い・霊媒の結果、人狼の相談は見る権限のある本人だけに届きます。全員の役職は終了時に公開します。画面の「ルールを見る」で、役職と時間切れ時の扱いを確認できます。

全生存者が同意すると、夜・議論・投票の残り時間をスキップできます。夜は全員が対象を決定してから同意します。村人・霊媒師・狂人も見回る相手を選ぶので、操作の有無では役職を判断できません。見回りはゲームの結果に影響せず、夜の対象と操作状況は本人だけに表示します。

- **Python・FastAPI**：ルーム、役職の行動、投票、勝敗を管理します。
- **WebSocket・JavaScript**：各プレイヤーに合わせた状態を配信し、画面を更新します。
- **サーバのタイマー**：クライアントの操作や接続の有無にかかわらず、制限時間で次の段階へ進みます。
- **SQLite・Cookie**：SNSと共通の参加情報を使います。

ゲームではJavaScriptを有効にしてください。接続が切れても同じブラウザで開き直すと復帰できます。ルームとゲームはメモリに保存するため、サーバを再起動すると消えます。
