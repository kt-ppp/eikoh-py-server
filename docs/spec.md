# 簡易仕様書

授業用のPython/FastAPI試作サーバです。SNSと人狼ゲームを提供し、参加情報は共通で使います。

## 起動と画面

Python 3.10以上が必要です。リポジトリのルートで `./start.sh`（Windowsでは `start.bat`、PowerShellでは `.\start.bat`）を実行すると、初回は仮想環境と依存関係を用意してから起動します。停止は `Ctrl+C` です。

- `/`：`app/apps/` のアプリ一覧。リポジトリのルートにある `index.html` を表示
- `/app/sns/`：参加と投稿の画面
- `/app/werewolf/`：人狼のルーム作成・参加

## SNSの操作

- 名前は1〜30文字。前後の空白を除き、有効な参加情報と同じ名前での参加を拒否します。期限切れになった名前は再利用できます。
- 投稿は1〜500文字。前後の空白を除き、空白だけの投稿は拒否します。画面には最新100件を表示します。
- 編集・削除は自分の投稿だけに許可します。JavaScriptが有効な場合は削除前に確認を表示し、「キャンセル」を選ぶと投稿を残します。

名前を入力する方式で、パスワードによる本人認証は行いません。投稿の所有者は名前ではなく、サーバが発行する `user_id` で判定します。画面にボタンがなくても、他人の投稿への操作はサーバで拒否します。

入力が不正な場合は400、名前の重複は409、他人の投稿への操作は403、存在しない投稿への操作は404を返します。

## 参加情報と保存

ブラウザは `session` Cookieで参加情報を送ります。標準の有効期限は参加から6時間で、アクセスしても延長しません。同じブラウザは期限まで参加情報を使い続けます。

期限切れ後に参加し直すと新しい `user_id` になります。以前の参加情報で書いた投稿は編集・削除できなくなります。

| データ | 保存先 | サーバ再起動後 |
| --- | --- | --- |
| 参加情報 | SQLiteの `data/sessions.sqlite3` | 有効期限まで使える |
| 投稿 | Pythonのメモリ、最新100件 | 消える |
| 人狼のルーム・ゲーム | Pythonのメモリ | 消える |

DBにはCookieのtokenそのものではなく、SHA-256ハッシュを保存します。Cookieには `HttpOnly` と `SameSite=Lax` を設定します。

## 人狼の操作

4〜16人で遊びます。ルーム作成者が役職の人数と夜・昼の議論・投票の時間を設定し、参加用リンクか6文字のコードを共有します。4人以上集まったら作成者が開始します。作成者自身もプレイヤーとして参加します。

役職は村人・人狼・占い師・騎士・霊媒師・狂人です。サーバが役職をランダムに配布し、時間で進行、投票の集計、勝敗判定を行います。人狼を全員処刑すると村人陣営の勝利、生存する人狼が人狼以外の人数以上になると人狼陣営の勝利です。30日目まで決まらなければ引き分けになります。

役職や私的な結果は本人にだけ表示し、全役職は終了時に公開します。ルーム作成者もほかの人の秘密情報は見られません。詳しいルールは画面の「ルールを見る」で確認できます。

昼の議論は対面の会話でも公開チャットでも行えます。対面で話す場合はチャットへの入力は不要です。

夜・議論・投票は、全生存者の同意で残り時間をスキップできます。全員が同意するまでは取り消せます。同意は次の時間に持ち越しません。投票のスキップでは現在の票を集計し、未投票を棄権として扱います。

夜は全生存者が対象を決定します。村人・霊媒師・狂人も見回る相手を選びますが、襲撃・占い・護衛の結果には影響しません。夜の対象と操作状況は本人にだけ表示し、自分の対象を決定してからスキップに同意できます。

ゲームにはJavaScriptが必要です。接続が切れても時間で進み、同じブラウザで開き直すと復帰できます。途中参加・ゲーム中の退室はできません。終了後は同じルームで次のゲームを準備できます。

## 通信と使用技術

Python・FastAPIで処理し、Uvicornで起動します。画面はJinja2・HTML・CSSで作り、JavaScriptで更新します。

参加後は `/app/sns/ws` にWebSocketで接続し、JSONで投稿・編集・削除を送ります。変更は接続中のブラウザに配信され、再読み込みせずに表示されます。通信が途切れると再接続し、参加情報が期限切れになると参加画面に戻ります。

WebSocketが使えない場合もHTTPフォームで操作できます。フォームでの変更もWebSocketへ配信します。名前や本文にHTMLが含まれていても、文字として表示します。

人狼は `/app/werewolf/rooms/{code}/ws` に接続し、各プレイヤー用の状態を受け取ります。時間の管理はサーバ側で行うため、ブラウザを閉じてもゲームは進みます。

投稿・ルーム・WebSocket接続はプロセス間で共有しないため、サーバは1プロセスで起動します。

## 設定

起動前の環境変数で変更できます。

| 変数 | 標準値 | 用途 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | 待ち受けアドレス（他端末から接続する場合は `0.0.0.0`） |
| `PORT` | `8000` | 待ち受けポート番号 |
| `SESSION_TTL_SECONDS` | `21600` | 参加情報の有効時間、秒 |
| `SESSION_DB_PATH` | `data/sessions.sqlite3` | SQLiteファイルの保存先 |
| `COOKIE_SECURE` | `false` | `true` でCookieをHTTPSに限定 |

HTTPS環境では `COOKIE_SECURE=true` を指定し、リバースプロキシでHTTPとWebSocketを転送します。ブラウザは `wss://` で接続します。
