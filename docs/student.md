# このアプリについて

## 1. 小さな投稿アプリ

`/app/sns/` は、複数の人が同じサーバにアクセスして、投稿を共有する仕組みを確かめるための簡単な例です。
名前を入力して「参加」を押すと、文章を投稿できます。ほかの人の投稿を見るときは、ページを再読み込みしてください。自動では更新されません。

## 2. ブラウザとサーバ

ブラウザは、Webページを見るためのアプリです。サーバは、みんなからのお願いを受け取って、ページを返すコンピュータです。
このアプリでは、HTTPという決まりに沿ってやり取りします。HTTPSは、そのやり取りを暗号化する仕組みです。

```text
自分のブラウザ
      ↓
  HTTP / HTTPS
      ↓
    サーバ
      ↓
ページをブラウザに返す
```

## 3. 投稿すると何が起きるか

```text
「こんにちは」と入力
↓
「投稿する」ボタンを押す
↓
文章をサーバに送る
↓
サーバがメモリに保存する
↓
投稿を含むページを表示する
```

保存先は、自分のブラウザではなくサーバです。みんなが同じサーバにアクセスするので、同じ投稿を見ることができます。
投稿は1〜500文字で、空白だけの文章は送れません。最新の100件が残ります。

## 4. 名前とユーザー

参加すると、表示する名前 `name` と、その人を区別する番号 `user_id` が結び付きます。
名前は1〜30文字です。同じ名前の人がいても、サーバの中では別々の `user_id` で区別できます。

## 5. セッション

一度参加すると、その授業中は毎回名前を入力しなくても、同じ人として扱われます。この一時的なつながりを「セッション」と呼びます。
ブラウザは、参加時にもらったランダムな合い言葉をCookieという小さな保存場所に持ち、次にアクセスするときにサーバへ送ります。

標準では、参加から6時間たつと参加し直す必要があります。アクセスしても期限は延びません。
サーバを再起動した場合も、もう一度参加してください。ずっと使うアカウントは作りません。

## 6. 今回はモック

このSNSは、完成したサービスではなく、仕組みを試すためのモック（小さな試作品）です。

- サーバへデータを送る
- サーバがデータを持つ
- ほかの人も同じデータを見る

この3つの基本を確かめるために作っています。データはサーバのメモリにだけ置かれ、サーバを再起動すると参加情報も投稿もすべて消えます。

## 7. 将来のゲームとの関係

今は「こんにちは」という文章を送っています。将来ゲームを作るときには、例えば次のような情報をサーバへ送ることが考えられます。

- 右へ移動した
- ジャンプした
- 投票した
- カードを出した

現在のコードには、ゲームやこれらの操作はまだ実装されていません。まずは、この投稿アプリで「送る・保存する・共有する」を体験してみましょう。
